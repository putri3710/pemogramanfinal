
# AI Tutor Bahasa Indonesia

Aplikasi pembelajaran Bahasa Indonesia
berbasis Python dan Streamlit.

## Fitur Aplikasi

- Materi pembelajaran
- Tanya jawab berdasarkan database
- Kuis dan penilaian otomatis
- Absensi siswa
- Bookmark materi
- Riwayat nilai siswa

## Teknologi

- Python
- Streamlit
- Database TXT dan JSON

## Cara Menjalankan

Jalankan perintah berikut pada terminal:

python -m streamlit run app_pengembangan.py
